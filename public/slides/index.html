Premise

Git tracks what agents wrote.
Premise tracks what they assumed.

Many AI coding agents change one codebase at the same time. When an assumption breaks, Premise stops that work before it lands.

Built on Cloudflare Workers and Artifacts

This is Premise. Git keeps track of what AI agents wrote. Premise keeps track of what they assumed, and redoes the work when an assumption breaks. [NEXT SLIDE]

The ledger gives one of three answers.

Wait

Pause until the other one lands. Then ask again.

Split

Depend

This work depends on the other. Pause until it lands.

A fixed rule decides, not a model. If it cannot, a person is asked.

It is one Worker on Cloudflare: the API, the page, and the TypeScript compiler. [→] Code lives in Artifacts: trunk, and a fork for every Intent. [→] State lives in Durable Objects: the ledger, each Intent, the gate, the event log. [→] Each agent is a Workflow. [→] Tests run in Dynamic Workers: a fresh isolate each time, with no network.

Here's a real example. Agent 1 changes a function called verifySession. It used to throw an error when a session expired. Now it just returns null. But Agent 2 wrote code that catches that error and writes an audit entry. After the change, there's no error to catch, so the audit entry quietly never gets written. And nothing complains.

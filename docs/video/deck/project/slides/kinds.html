There are actually two kinds of Intent. An agent Intent is a real task, like a ticket: an agent reads the code, writes the change and its tests, and says what it relies on. A workload Intent is much simpler: a small edit made by a script, with no agent and no AI. Those are just background traffic, so we can see how Premise holds up when lots of changes are landing at once. Both kinds go through the same ledger and the same gate. [NEXT SLIDE]
